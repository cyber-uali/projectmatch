# ProjectMatch — прототип платформы

Учебный проект: AI-платформа для школьников 15–18 лет, которая помогает находить
тиммейтов и доводить собственные идеи до результата.

**Живая версия: https://cyber-uali.github.io/projectmatch/**

Сейчас готов **первый экран — лендинг**. Остальные экраны (профиль, AI Matching,
Team Workspace) добавляются следующими шагами.

## Как открыть

Вариант 1 — просто дважды кликнуть `index.html`. Всё работает офлайн
(шрифты подключаются из Google Fonts, без интернета останется системный шрифт).

Вариант 2 — локальный сервер (удобнее, если планируется несколько страниц):

```powershell
node --version           # нужен Node.js
npx serve .              # или любой другой статический сервер
```

## Структура

```
ProjectMath/
├─ index.html            # лендинг
├─ assets/
│  ├─ css/styles.css     # дизайн-система + все стили
│  └─ js/main.js         # меню, анимации, счётчики, кольца совпадения
└─ README.md
```

### Что где менять

| Задача | Где |
| --- | --- |
| Тексты, профили, задачи на канбане | `index.html` — это обычная разметка, mock-данные вписаны прямо в неё |
| Цвета, шрифты, отступы | `assets/css/styles.css`, блок `:root` в начале файла |
| Анимации появления | класс `.reveal` + `data-delay` |
| Процент совпадения | атрибут `data-p` у блока `.ring` |

## Реализовано

- адаптивный лендинг (проверено на 390, 900, 1100, 1280, 1440 px);
- липкий хедер с мобильным меню;
- hero-блок с макетом карточки мэтчинга и кольцом совпадения (анимация при скролле);
- бегущая строка направлений проектов;
- «Как это работает» — 3 шага;
- bento-сетка возможностей: AI Matching, Team Workspace (мини-канбан), прогресс, философия;
- демо-подбор из трёх профилей + обязательная плашка «это демонстрация алгоритма»;
- блок исследования (Research Paper / Findings / Business Model);
- финальный CTA и футер;
- доступность: skip-link, aria-атрибуты, focus-visible, поддержка `prefers-reduced-motion`;
- контент виден без JS (анимации подключаются классом `.js`).

## Что дальше

## Публикация

Прототип статический — подойдёт любой бесплатный хостинг:

- **GitHub Pages** (используется сейчас): репозиторий `cyber-uali/projectmatch`,
  Settings → Pages → Deploy from branch `main` / root.
- **Netlify**: drag & drop папки на app.netlify.com/drop.

### Обновить сайт после правок

```powershell
git add -A
git commit -m "правки"
git push
```

GitHub Pages пересоберёт сайт за 30–60 секунд, ссылка не меняется.
