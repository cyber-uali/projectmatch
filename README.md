# ProjectMatch — прототип платформы

Учебный проект: AI-платформа для школьников 15–18 лет, которая помогает находить
тиммейтов и доводить собственные идеи до результата.

**Живая версия: https://cyber-uali.github.io/projectmatch/**

Сейчас готовы **лендинг и поиск тиммейтов**: база учебных профилей с фильтрами,
профилем кандидата и приглашениями. Остальные экраны (свой профиль, Team Workspace)
добавляются следующими шагами.

## Как открыть

Вариант 1 — просто дважды кликнуть `index.html`. Всё работает офлайн
(шрифты подключаются из Google Fonts, без интернета останется системный шрифт).

Вариант 2 — локальный сервер (удобнее, если планируется несколько страниц):

```powershell
node --version           # нужен Node.js
npx serve .              # или любой другой статический сервер
```

## Структура

```
ProjectMatch/
├─ index.html             # лендинг (разметка с data-i18n-ключами)
├─ search.html            # поиск тиммейтов: запрос, фильтры, профили
├─ assets/
│  ├─ css/
│  │  ├─ styles.css       # дизайн-система + лендинг
│  │  └─ search.css       # компоненты страницы поиска
│  └─ js/
│     ├─ i18n.js          # словарь текстов: русский + қазақша
│     ├─ data.js          # сид базы: роли, интересы, синонимы, 40 профилей
│     ├─ db.js            # база: localStorage + избранное и приглашения
│     ├─ search-engine.js # поиск: синонимы, морфология, релевантность
│     ├─ search-page.js   # страница поиска: карточки, фильтры, профиль
│     └─ main.js          # меню, анимации, счётчики, кольца совпадения
├─ research/              # опрос для Research Paper (формы, вопросы, скрипт)
└─ README.md
```

### Что где менять

| Задача | Где |
| --- | --- |
| Профили, роли, интересы в базе | `assets/js/data.js` (после правок поднимите `VERSION`) |
| Логика и веса поиска | `assets/js/search-engine.js`, массив `FIELDS` |
| Интерфейс поиска | `search.html` + `assets/css/search.css` |
| Тексты на двух языках | `assets/js/i18n.js` — блоки `ru` и `kk`, ключи совпадают |
| Разметка, профили, задачи на канбане | `index.html`; текст помечен `data-i18n="ключ"` |
| Цвета, шрифты, отступы | `assets/css/styles.css`, блок `:root` в начале файла |
| Анимации появления | класс `.reveal` + `data-delay` |
| Процент совпадения | атрибут `data-p` у блока `.ring` |

### База данных и поиск

Проект статический, поэтому «база» — это `data.js` + слой `db.js`:

- при первом открытии профили из `data.js` копируются в `localStorage`
  (ключ `pm-db-v1`), дальше страница работает с локальной базой;
- избранное и отправленные приглашения тоже сохраняются и не теряются
  при перезагрузке; «Сбросить» в фильтрах их не удаляет;
- если нужно обновить профили — измените их в `data.js` и увеличьте `VERSION`:
  база перезапишется, избранное останется;
- при переходе на реальный бэкенд (Supabase / Google Sheets) меняются только
  внутренности `db.js` — поиск и интерфейс обращаются к готовому API
  (`PM_DB.list()`, `get`, `favorites`, `invite` и т.д.).

Поиск (`PM_SEARCH`) понимает:

- **имя** — «Маша», «клим» (достаточно начала слова);
- **роль** — «дизайнер», «дизайнеры», «дизайнеров» → все дизайнеры;
- **синонимы** — «программист» → frontend/backend, «пайтон»/«питон» → Python,
  «фигма» → Figma, «стм32» → STM32, «зерттеуші» → исследователи;
- **навыки и интересы** — «React», «эко», «нейросети»;
- **фильтры** — роль, интересы, класс, занятость, только избранное.

Все слова запроса обязательны (как в обычном поиске): «дизайнер алматы»
найдёт только дизайнеров из Алматы. Каждое слово допускает опечатку в один
символ. Результаты сортируются по релевантности, имени или классу.
Состояние поиска сохраняется в адресе страницы — ссылкой можно поделиться:
`search.html?q=дизайнер&role=designer&sort=grade`.

Горячая клавиша `/` ставит курсор в строку поиска.


### Языки

Переключатель в шапке меняет язык мгновенно и запоминает выбор в `localStorage`.
Язык можно задать и ссылкой: `?lang=ru` или `?lang=kk` — удобно для показа.
Чтобы добавить третий язык, скопируйте блок в `i18n.js` и добавьте кнопку
с `data-lang` в шапку: разметку переписывать не нужно.

## Реализовано

- два языка: русский и казахский (переключатель РУС / ҚАЗ в шапке);
- адаптивный лендинг (проверено на 390, 900, 1100, 1280, 1440 px);
- липкий хедер с мобильным меню;
- hero-блок с макетом карточки мэтчинга и кольцом совпадения (анимация при скролле);
- бегущая строка направлений проектов;
- «Как это работает» — 3 шага;
- bento-сетка возможностей: AI Matching, Team Workspace (мини-канбан), прогресс, философия;
- демо-подбор из трёх профилей + обязательная плашка «это демонстрация алгоритма»;
- блок исследования (Research Paper / Findings / Business Model);
- финальный CTA и футер;
- **поиск тиммейтов**: 40 профилей, поиск по имени/роли/навыку/интересу,
  синонимы и простая морфология, фильтры по роли, интересам, классу и занятости,
  сортировка, счётчики совпадений;
- **профиль кандидата** в диалоге: навыки, интересы, кого ищет, число проектов;
- **избранное и приглашения** с сохранением в браузере (база в `localStorage`);
- **шаринг поиска ссылкой**: `search.html?q=дизайнер&role=designer`;
- доступность: skip-link, aria-атрибуты, live-регион счётчика, `focus-visible`,
  поддержка `prefers-reduced-motion`, закрытие профиля по Esc;
- контент виден без JS на лендинге (анимации подключаются классом `.js`).
