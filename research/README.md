# Исследование: опрос для школьников

Всё, что нужно, чтобы собрать реальные данные для Research Paper и одновременно
получить поля для мэтчинга на сайте.

## 1. Создать формы (один раз, ~2 минуты)

1. Открой <https://script.google.com> → **Новый проект**.
2. Удали код-заглушку (`function myFunction() {}`) и вставь содержимое
   [`google-form.gs`](./google-form.gs).
3. Нажми **Выполнить** (▷). Google попросит разрешения — разреши
   (скрипт создаёт только формы и таблицы, ничего не читает и не удаляет).
4. Открой **Журнал выполнения** (Ctrl+Enter) — там ссылки на **две формы**
   (русскую и казахскую), две ссылки для учеников и две таблицы с ответами.

Google Forms не умеет переключать язык внутри одной формы, поэтому их две.
Вопросы, их порядок и порядок вариантов в обеих формах совпадают — ответы
можно объединить при анализе. На сайте язык переключается кнопкой РУС / ҚАЗ,
а в форме — выбором подходящей ссылки.

Если скрипт не хочется запускать — собери форму вручную по тексту
[`questions.md`](./questions.md), там все формулировки и типы вопросов.

## 2. Перед рассылкой проверить

- [ ] В настройках **обеих** форм: **Ответы → Собирать адреса электронной почты — выключено**.
- [ ] **Настройки → Ограничить 1 ответом — выключено** (иначе ученикам придётся
      входить в Google-аккаунт, а младшим он часто недоступен).
- [ ] Тестовый проход каждой формы с телефона — 2 минуты, всё читается.
- [ ] В конце есть ссылка на прототип.

### Если запуск упал с ошибкой

Скрипт создаёт формы по одной, поэтому после ошибки в Drive могли остаться
недоделанные формы — удали их, исправь код и запусти заново. Повторный
успешный запуск создаст новые формы и новые таблицы ответов.

## 3. Текст для класса

> Привет! Мы делаем ProjectMatch — сервис, который помогает находить команду
> для своих проектов. Ответь, пожалуйста, на короткий анонимный опрос (3–5 минут).
> Это реально поможет: по ответам мы поймём, чего не хватает школьникам, чтобы
> начать своё дело. Ссылка: **[вставить ссылку]**

Для учителя / классного руководителя:

> Здравствуйте! Мы исследуем, почему школьникам сложно доводить свои идеи до
> проекта, и разрабатываем платформу для поиска команды. Опрос анонимный, почту
> не собирает, занимает 3–5 минут, результаты используются только в обобщённом
> виде в учебном исследовании. Ссылка: **[вставить ссылку]**

### На казахском (для классов с казахским языком обучения)

> Сәлем! Біз ProjectMatch жасап жатырмыз — өз жобаларыңа команда табуға
> көмектесетін сервис. Қысқа анонимді сауалнамаға жауап берші (3–5 минут).
> Жауаптарың бойынша оқушыларға не кедергі екенін түсінеміз.
> Сілтеме: **[сілтеме]**

Для учителя:

> Сәлеметсіз бе! Біз оқушылардың идеяларын жобаға жеткізуде неге қиналатынын
> зерттеп, команда табуға арналған платформа жасап жатырмыз. Сауалнама анонимді,
> пошта жиналмайды, 3–5 минут. Нәтижелер тек оқу зерттеуінде жалпыланған түрде
> қолданылады. Сілтеме: **[сілтеме]**

## 4. Когда придут ответы

- Ответы попадают в две таблицы: «ProjectMatch — ответы на опрос (РУ)» и
  «ProjectMatch — сауалнама жауаптары (ҚАЗ)».
- Для анализа: **Файл → Скачать → CSV** из каждой таблицы и пришли оба файла —
  я объединю их (порядок вопросов и вариантов одинаковый), посчитаю распределения,
  соберу диаграммы для Research Findings и подготовлю данные для профилей на сайте.
- Минимум для выводов: **30+ ответов**, комфортно — 60–100.
  Если классов много, попроси пройти в 3–4 параллелях.

## 5. Приватность (не пропускай)

- В публичном репозитории и на сайте **не должно быть** имён, почт, телефонов
  и школ реальных учеников.
- Для публичной демо-версии используем обезличенные профили: имя + первая буква
  фамилии, без контактов.
- Контакты из последнего раздела формы (если кто-то их оставил) храним отдельно
  и не выгружаем в сайт.
- В тексте исследования и на защите используем только агрегированные цифры
  («72 % ответили, что…»), без цитат с именами.

## 6. Что дальше

1. Собрать ответы.
2. Прислать CSV → я делаю сводку и диаграммы.
3. На основе полей опроса собираем базу профилей и включаем реальный мэтчинг
   на сайте (Supabase или Google Sheets как бэкенд — обсудим, когда будут данные).
